# 博物馆与校史馆

同济大学博物馆和校史馆展示内容不同:博物馆以建筑、园林、机械、传统艺术等专题展览为主;校史馆以同济大学的办学历程、人物、档案和校园文化为主。两馆均可免费参观,开放时间在节假日、寒暑假或举办重要活动时可能调整,出发前应查看各自官网的最新通知。

## 同济大学博物馆

### 在哪里?看什么?

[同济大学博物馆](https://museum.tongji.edu.cn/)位于四平路校区一二九大楼内,在一二九礼堂西侧。一二九大楼始建于 1942 年,本身也是上海市优秀历史建筑。

馆内常设内容主要包括:

- **中国园林与传统艺术展示厅**:园林模型、传统家具微缩模型、非遗藏品和书画作品等;
- **中国古代机械复原模型展示厅**:农业、手工业、起重运输、战争器械和自动机械等复原模型;
- **中国建筑与建筑文化展示厅**:中国古代建筑、传统民居及同济人在文化遗产保护方面的实践。

除常设展外,博物馆还会举办艺术、设计、科技和传统文化等临时展览,当前展览应以[博物馆新闻资讯](https://museum.tongji.edu.cn/35365/list.htm)为准。

### 怎么参观?

| 事项 | 信息 |
| --- | --- |
| 开放时间 | 周一至周六 8:30-16:30,16:00 后停止入馆 |
| 参观费用 | 免费 |
| 个人参观 | 通常可在开放时段直接前往;遇节假日或临时活动,以馆方公告为准 |
| 团体参观 | 10 人以上、需要讲解的团队可提前预约 |
| 团体预约 | 查看[团体预约页面](https://museum.tongji.edu.cn/35372/list.htm),咨询电话:021-65983563 |

入馆需要接受安全检查。大件包裹可按馆方要求寄存;展厅内不得使用闪光灯,也不要触摸展品。宠物、易燃易爆物品和其他危险物品不得带入馆内,具体要求见[博物馆参观须知](https://museum.tongji.edu.cn/35370/list.htm)。

## 同济大学校史馆

### 在哪里?看什么?

[同济大学校史馆](https://gtjuh.tongji.edu.cn/)现馆名为"同创楼",位于四平路校区东侧。展览通过照片、档案、实物、模型和影像等材料,介绍学校自 1907 年创办以来的迁校、办学和发展历程,也展示同济与国家建设、城市发展及不同学科演进之间的联系。

第一次参观时,可以重点留意学校早期医学与德文教育、抗战时期内迁办学、院系调整、恢复综合性大学建设,以及"同舟共济"如何逐渐成为学校精神标识。校史馆一楼也会设置档案和人物主题的临时展览。

**在嘉定校区东南角也设有校史馆**,有需要的同学可以自行参观,规定相似,但并没有在网络公示,故按下不表。

### 怎么参观?

根据现行[校史馆开放管理规定](https://gtjuh.tongji.edu.cn/cgxz/list.htm),校史馆向师生、校友、学生家长和社会公众免费开放。

| 事项 | 信息 |
| --- | --- |
| 日常开放 | 8:30-16:30;法定节日及寒假闭馆,临时调整以公告为准 |
| 团体接待 | 周一至周五 8:30-11:30、13:30-16:30 |
| 团体预约 | 原则上提前 3 个工作日提交预约,由校史馆确认具体时间 |
| 联系电话 | 021-65981073 |
| 校外团队进校 | 按学校进校规定办理,预约规定提示团队从赤峰路 50 号校门步行入校 |

个人参观时应按要求登记并听从工作人员引导。未成年人需要成年看护人陪同;馆内禁止吸烟、用餐、追逐和触摸展品,未经允许不要自行组织讲解、拍摄工作人员或开展商业活动。

## WIKI Tips

- 新生不用特别跑一趟,本科新生教育期间会组织大家统一参观;
- 不要把两馆当成同一个地方。博物馆在一二九大楼,校史馆现阶段在四平路校区东侧的同创楼;从一个馆走到另一个馆前应重新查看校园地图;
- 寒暑假和节假日一定先查公告。两馆的常规开放时间不能直接套用到学校假期,临时布展、活动接待也可能影响参观;
- 想听讲解要提前约。个人随到参观通常不等于现场一定有讲解;班级、社团或课程组织集体参观时,应由负责人按团体流程预约;
- 拍照前先看现场标识。博物馆允许在遵守规定的前提下拍照,但不得使用闪光灯,部分临展也可能另有限制;校史档案和实物同样应以现场要求为准。

## 进一步探索

1. [同济大学博物馆](https://museum.tongji.edu.cn/):查看当前展览、数字展厅和临时开放通知;
2. [同济大学博物馆参观须知](https://museum.tongji.edu.cn/35370/list.htm):开放时间、安全检查和拍摄要求;
3. [同济大学校史馆](https://gtjuh.tongji.edu.cn/):查看校史展览、工作动态和参观信息;
4. [同济大学校史馆开放管理规定](https://gtjuh.tongji.edu.cn/cgxz/list.htm):个人与团体参观要求、预约和联系方式。
